# 訂單同步與 Factory Board 修改報告

- 日期：2026-08-31
- 環境：FCCD 生產環境／本地工作區
- 涉及範圍：Bubble 訂單同步、Shopify 訂單同步、Factory Board

## 一、修改目的

本次工作主要處理以下問題：

1. 取消把便當菜名末端的配菜括號內容拆成獨立備註。
2. 修正 Shopify 飯盒選項最後一項不是飲料時被錯誤刪除的問題。
3. 補回 Bubble 同步後遺失的明細備註。
4. 清理重複菜式及不再適用的訂單備註。
5. 調整 Factory Board 頁首按鈕排列。
6. 訂單編輯期間，以遮蓋層鎖定操作區，避免誤操作或打印。

## 二、同步程式修改

### 2.1 取消便當配菜括號拆分

原有修改會把下列菜名：

`(便當) 咕嚕雞球飯 (獅子頭、時菜、涼菜)`

拆成菜名及獨立備註。現已取消此行為，完整內容會保留在菜名中，不再另外產生 `remarks_1`。

### 2.2 修正飯盒選項遺失

舊邏輯固定刪除 Shopify variant 的最後一個選項，假設最後一項一定是飲料。若最後一項是 `蕃茄沙律`，便會錯誤遺失。

新邏輯只會在最後一項確定屬於飲料時移除；非飲料選項會保留為操作備註。

例子：

- `蕃茄沙律` → 保留 `蕃茄沙律`
- `蕃茄沙律 / 蜂蜜綠茶` → 保留 `蕃茄沙律`，飲料另建明細
- `蜂蜜綠茶` → 不建立菜式備註，飲料另建明細

### 2.3 部署狀態

`shopify-order-sync` Edge Function 已部署至生產 Supabase 專案 `vignxasvlxqnyvuhtjlu`。

## 五、Factory Board 介面修改

### 5.1 頁首按鈕排列

- 左右日期箭嘴及「去今日」置於頁首正中間。
- 「出餐日曆」、「指定日期」及「多日菜式總表」按鈕群靠右。
- 手機版維持自動換行及置中排列。

### 5.2 訂單編輯鎖定畫面

訂單正被修改時：

- 菜式卡片及右側操作按鈕區會被 75% 黑色遮蓋層覆蓋。
- `訂單正在修改，請先不要打印` 置於遮蓋層正中央。
- 提示文字及警告圖示已加大，方便遠距離辨識。
- 遮蓋層不顯示紅色外框。
- 菜式選取、打印、分派司機及打印機選擇均不能操作。
- 訂單編號、日期、送達時間、地址及客戶資料仍可查看。

### 5.3 訂單卡片及小視窗顯示

- 訂單卡片的 `訂單修改中` 改為放在主要文字下方的滿寬標籤，樣式與 `有更改` 一致，不顯示圖標。
- 小高度視窗會縮小菜式、數量及備註字體與間距，保留完整資訊。
- 菜式卡片會隨備註內容自動增高，備註可完整換行，不再被卡片邊界裁掉。
- 菜式操作區仍可垂直捲動。
