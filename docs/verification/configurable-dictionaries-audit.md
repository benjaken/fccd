# 可配置選項排查

## 已改為通用字典

以下業務選項由 `dict_types` / `dict_items` 管理，統一在「系統設定 → 字典配置」維護：

- 食材類型
- 餐廳員工部門、僱傭類型
- 餐廳庫存部門、盤點部門
- 送貨時段、出車時間
- 報價狀態
- 報價條款、付款方式、額外資訊、活動項目模板
- 每月 P&L 分類
- 中央廚房廣告節日
- 訂單手動待辦
- 供應商報價單位
- 產品及套餐狀態
- 產品價格區間

已停用的字典項目不再出現在新記錄的選項中；編輯舊記錄時仍保留其既有值，避免資料被意外清空。字典的 `value` 是業務記錄使用的穩定識別值，顯示名稱及英文名稱可以獨立修改。

## 已有資料庫配置，不重複建立字典

下列選項原本已由獨立主資料表或設定頁維護，因此直接使用現有資料，不再建立第二份字典：

- 品牌、供應商、產品、地區、送貨方式、付款方式、銷售來源、溝通渠道
- 餐廳、餐廳部門、服務時段、外賣平台、假期、更表時間
- 廚房節日及廣告渠道的實際報表資料
- 供應商費用類別、餐廳每月 P&L 費用項目

訂單列表的節日及地區篩選直接讀取 `festivals` 與 `delivery_districts`，並按訂單的 `festival_id` 及送貨記錄的 `district_id` 篩選。地區在「系統設定 → 地區管理」維護；地區名稱會去重顯示，但查詢時仍涵蓋同名的既有地區記錄。

## 保持固定的程序選項

以下值會改變程序分支、資料格式或受資料庫約束，並非可任意新增的業務主資料，因此不放入通用字典：

- 日期篩選模式：單日／範圍／多日
- 檔案類型：全部／文件／圖片
- 數值運算：增加／扣減
- PDF 插頁位置：封面前／封面後
- 報價送貨時間的「自訂」輸入模式
- 生肉重量單位：與重量換算規則及型別校驗綁定

報價狀態的可選項及顯示名稱已移入字典，但 `Done Deal`、`Case Closed` 等流程識別值仍被轉單及自動關閉邏輯使用，因此不應修改其 `value`；需要改顯示文字時只修改 `label`。

訂單手動待辦的狀態映射、產品價格區間的上下限，以及產品狀態是否啟用等程序資料存放在字典項目的 `metadata`。這些項目可以在系統設定調整名稱、排序及啟停；修改穩定 `value` 或 `metadata` 前仍需確認相應流程含義。
