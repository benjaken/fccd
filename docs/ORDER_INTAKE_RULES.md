# 通用接單安排

中秋、聖誕、春節及臨時繁忙日共用同一套規則。在「訂單設定 → 接單安排」設定資料，不需要為每個節日新增程式分支。

## 每項安排

- 名稱與開始／結束日期：包含兩端日期；跨年可用不同年份。
- 全日或指定時段：每天套用同一時段，包含開始時間、不包含結束時間。例如 17:00–19:00 包含 18:59，不包含 19:00。跨午夜安排需拆成兩項。
- 新單處理：人工覆核，或只接受指定品牌及產品。
- 每個品牌分別設定允許產品名稱／標籤關鍵字，可選填品牌別名。
- 自助加購：獨立設定人工覆核或沿用一般安排。一般安排仍受原有截止時間及可加購產品限制。
- 客人訊息與內部備註：內部備註不作客人答覆。

空白的新安排沒有預設節日產品。每個選取的可接品牌必須填寫產品條件。編輯名稱或訊息不會合併不同品牌的產品，也不會更改加購政策。

## 判斷順序

1. 先識別完整訊息的意圖；投訴、取消、查單及轉真人不能被時間或產品名稱攔截。
2. 從已保存的日期、送達時間及客人目前的選擇核對安排。客人更改日期／時間時，以新值為準。
3. 所有同時命中的品牌／產品限制都必須符合；任何人工覆核規則優先。
4. 有指定時段規則但尚未提供送達時間，須追問時間，不能把產品符合條件視為時段也可接單。
5. 每個品牌只能使用自己的產品關鍵字搜尋啟用中的產品資料。重疊規則的推薦產品取共同允許的產品。
6. 客人選產品時重新核對現行安排，保留已提供的送達時間；不以舊推薦取代目前判斷。
7. 資料庫查詢失敗或結果未知時，保留上下文並說明未能確認，不承諾可落單。

管理員須明確設定規則日期。系統不會按節日名稱推算公曆／農曆日期，也不會自動每年重複；下一年的日期及產品由管理員確認後建立。

客人可使用相對日期查詢：按香港曆日，「星期日」表示最近一個星期日（包含今天），「今個星期日」及「下星期日」分別按本週及下週計算，週一為一週開始。「今日／明天／後天」也會換算成實際日期。回覆會列明查詢日期；明確年月日優先。無法確定單一日期時先追問，不把空日期送往資料庫。
