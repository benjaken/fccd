# Food Channel Catering Sitemap

> 狀態：已確認的 Sitemap 草案
> 原則：第一階段先實現現有功能；標記為「第二階段」的功能不納入第一階段。

## 全域頂部

```text
工作區
├─ 到會／中央廚房
├─ 司機送貨
├─ 餐廳營運
└─ 客戶自助【第二階段】

工具
├─ 全域搜尋
├─ 繁中／English
├─ Light／Dark Mode
├─ 站內通知
└─ 使用者選單
   ├─ 個人資料
   └─ 登出
```
